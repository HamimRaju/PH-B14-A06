# FitLog

A modern, responsive web application built for tracking daily workout routines and organizing exercise plans. Users can explore a library of exercises, filter by categories, create custom daily routines, and save workouts for future sessions.

## Features

- **Exercise Library & Details:** Browse a collection of workouts with exercise details including duration, estimated calories, equipment needed, and step-by-step instructions.
- **Custom Daily Planning:** Add exercises directly to "Today's Plan" to structure your daily workout session with a hard limit of 5 exercises per day.
- **Save for Later:** Bookmark exercises to your saved list to organize future routines without cluttering your daily schedule.
- **Interactive Workout Progress:** Track completed exercises in real-time with progress status indicators and dynamic daily summaries (total duration, target calories, completed count).
- **Sorting & Filtering:** Easily filter exercises by muscle group or equipment, and sort plans by duration, calories burned, or rating.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React / Inline SVGs
